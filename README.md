# Data-Warehouse-Analytics-Platform
Design and implement an enterprise grade analytics data warehouse in MySQL. Medallion Architecture (Bronze → Silver → Gold).

---

## Project Plan

### Building the Data warehouse (Analytics Engineering)

#### Objective
Design and implement an enterprise-grade analytics data warehouse in MySQL by transforming a large real-world operational dataset into a trusted analytics-ready platform using the Medallion Architecture (Bronze → Silver → Gold). The project demonstrates relational database design, ETL development, dimensional modelling, SQL engineering, data quality management, and warehouse optimization following analytics engineering best practices.

---

### Business Problem
We are solving a data problem for Businesses.
Analysts spend significant time cleaning data, integrating information, and writing repetitive queries before generating insights. The absence of a centralized analytical warehouse limits reporting efficiency, data quality, and decision-making capabilities.
Building a high-performance data warehouse for analysis.

#### Scope
•	Raw crime dataset (Loading 1 Million rows of raw LAPD Crime Data (2020–Present) into a relational staging database)
•	Relational database
•	Normalized database
•	Enterprise Data Warehouse (Designing and deploying a Star Schema)
•	Bronze Layer
•	Silver Layer
•	Gold Layer
•	ETL Pipeline
•	SQL Engineering
•	Data Validation
•	Performance Optimization
•	Documentation

#### Out-of-Scope
•	Real-time streaming ingestion 
•	External API integrations for live data
•	Cloud Deployment
